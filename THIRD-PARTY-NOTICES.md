## Slint 1.18.1

The graphical interface is built with [Slint](https://slint.dev): the program contains code generated by the Slint compiler from `ui/`, and the Slint library ships beside it (`lib/libslint_cpp.so` on Linux, `bin/slint_cpp.dll` on Windows).

Slint is available under the GPLv3, under the Slint Royalty-free Desktop, Mobile and Web Applications License 2.0, or under a commercial license. resend uses it under the **Royalty-free License 2.0**, and discloses it as that license asks, with the `AboutSlint` widget in **Help ▸ About** ([decision 0001](docs/decisions/0001-license-and-name.md)). Anyone distributing their own build of resend chooses one of Slint's licenses in turn.

- Slint's license texts: `share/doc/resend/slint/LICENSE.md`.
- The licenses of the libraries compiled into the Slint library, listed by Slint: `share/doc/resend/slint/THIRDPARTY.md`.

## miniaudio 0.11.25

Sounds reach the sound card through [miniaudio](https://miniaud.io) by David Reid, compiled into the program ([decision 0005](docs/decisions/0005-audio-output.md)). miniaudio is available, at the user's choice, in the public domain under the Unlicense or under the MIT No Attribution license; neither asks for a notice, and resend gives one anyway. Its license text: `share/doc/resend/miniaudio/LICENSE`.

## Fonts

Built into the program, and installed with their license texts in `share/resend/fonts/`. All three are under the [SIL Open Font License 1.1](https://openfontlicense.org):

- [Pixelify Sans](https://github.com/eifetx/Pixelify-Sans), © 2021 The Pixelify Sans Project Authors (`OFL-PixelifySans.txt`)
- [Inter](https://github.com/rsms/inter), © 2020 The Inter Project Authors (`OFL-Inter.txt`)
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), © 2020 The JetBrains Mono Project Authors (`OFL-JetBrainsMono.txt`)

The Pixelify Sans files are modified: their default ligatures are turned off, because "fi" joined reads as another letter at the sizes the interface uses. `scripts/pixel-font-ligatures.py` makes the change, renaming the feature `liga` to `hlig`; the glyphs are untouched. The license allows modified versions, and the font declares no reserved font name.

## Windows: the Visual C++ runtime

The Windows packages carry Microsoft's Visual C++ runtime libraries (`msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll` and the others CMake's `InstallRequiredSystemLibraries` names), which the programs and the Slint library need. Microsoft allows them to be redistributed with applications as part of the Visual Studio *distributable code*.

## Linux AppImage: system libraries

The AppImage is built on Ubuntu 22.04 and carries the libraries the Slint library needs that not every distribution installs: libinput and the libraries it uses in turn. It does not carry those every desktop has (the C and C++ runtimes, fontconfig, FreeType, xkbcommon, Mesa, X11 and Wayland), following the AppImage project's exclude list. Inside the AppImage, `usr/share/doc/resend/bundled/` lists every library it carries with its Ubuntu package and version, and holds each package's copyright file. Their source code is that of those Ubuntu packages, available from the Ubuntu archive ([launchpad.net/ubuntu/+source](https://launchpad.net/ubuntu/+source)) at the versions listed.

The tar.gz package carries none of them: it uses the system's libraries (see the README).
